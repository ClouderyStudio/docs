## 使用前注意事项

白嫖一时爽，但涉及账号、额度甚至潜在扣费，建议先读完再操作：

1. **第三方站点属性**：本文涉及的站点大多为第三方聚合平台或中转站，并非 DeepSeek、Kimi、xAI 等官方渠道。模型、价格、额度均以对应平台页面为准。
2. **本站与链接的关系**：文中大部分为群友投稿的推广（aff/referral）链接，站方未与这些平台有任何合作，也不为其运营背书。是否使用请自行判断。
3. **先核验域名与隐私政策**：注册前先确认站点域名可访问、证书正常、隐私条款可接受；不要向陌生平台提交真实姓名、身份证号等敏感信息。
4. **留意自动扣费**：赠送/体验额度用尽后，不少平台会自动转为按量付费，甚至要求绑定支付方式。如需保留，先看价格表；不打算付费就关闭自动续费或解绑支付方式。
5. **API Key 与额度安全**：如果拿到的额度要配置到客户端/软件里，注意：
   - 不要把 API Key 发到群里、贴进公开帖子或提交到公开仓库；
   - 优先使用“额度用尽即停/限额”功能，防止意外超额扣费；
   - 同一 Key 不要到处使用，泄露后及时到平台吊销重建。
6. **时效信息随时变动**：赠送额度、邀请奖励和活动截止时间经常调整，以注册后平台页面显示的规则为准，本页不保证时效。
