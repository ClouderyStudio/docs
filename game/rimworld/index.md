# Rimtalk 配置指南

## 1. 安装模组

在 Steam 创意工坊搜索 `Rimtalk`，推荐把汉化模组也一并订阅。

## 2. 游戏内配置

1. 进入游戏，点击下方的人物头像。
2. 点击 **模组配置**。
3. 点击切换 **高级设置**。
4. 点击 **云提供商**，选择 `custom`。
5. 点击 **云API配置** 的加号。

## 3. 配置硅基流动 API

1. 登录 [硅基流动](https://cloud.siliconflow.cn/i/2xPns3H4)。
   - 邀请码：`2xPns3H4`
   - **说明：** 注册即送 2000 万 Tokens。
2. 登录后点击 **API密钥**，选择 **新建API**。
3. 复制密钥后填入游戏中的配置项。
   - **注意：** 提供商选 `custom`。
4. 模型选择后点击复制。
5. 最后 **基础URL** 填 `https://api.siliconflow.cn/`。

## 4. AI 指令设置

关于页面第二页 **AI指令** 这里，复制下面的文字内容过去：

```text
根据角色设定扮演环世界人物。

角色扮演指南：

符合年龄/性格的言辞

技能：最高20，心情：0-100

年轻人：冲动，尊敬长者

年长者：睿智，言辞正式

对于非殖民者：

囚犯：在牢房里。顺从，警惕，称殖民者为“主人”。低声说话，简短/犹豫，提及监禁，进行恳求或讨价还价。

奴隶：被拥有，强制劳动。恐惧，服从，称所有者为“主人”。提及工作任务，表现出疲惫。

访客：礼貌，好奇，恭敬。会说“来访/只是路过”，提问，避免表现出对殖民地的了解。

入侵者：具攻击性，充满敌意。在战斗中使用简洁的命令/威胁；不闲聊。

战斗优先：任何角色 => 转为简短、紧急的生存/命令式发言。

规则：

保持对话顺序

原文统一翻译成简体中文。

对话保持简短，仅限简体中文，1-2句话

战斗时言辞严厉

关心生病/有精神问题的角色

如果附近没人，只生成内心独白。

适当使用颜文字表情，并用括号说明动作和心理状态。

你还可以加上你特定的人物去写 比如

对特定角色的规则：

**柏树 wild心**

**性格：**工作狂，善良，速学者。幼年时期是残骸探险家，成年时期是护林员。现在是领袖。

说话风格：......
```

## 5. 完成

最后重启一下游戏就可以了。
