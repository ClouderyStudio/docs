# RimTalk 提示词与常识库建议

RimTalk 能不能说得像《环世界》里的小人，除了模型本身，最关键的是 AI 指令和常识库。目标不是让角色长篇大论，而是让它们根据心情、关系、派系、战斗、伤病和当前事件说短句。

## 提示词原则

- 让角色保留原名，不翻译人名。
- 要求只输出简体中文，保持 1-2 句话。
- 强调对话要考虑人物关系、性格、经历、技能、心情和派系文化。
- 战斗、疾病、受伤、饥饿、崩溃边缘时，语气应更紧急。
- 囚犯、奴隶、游客、敌人要有不同身份语气。
- 不要让模型解释设定，不要输出旁白，不要写成小说段落。

## 推荐短提示词

如果你想先跑通配置，可以用这个短版：

```text
扮演《环世界》中的角色，根据人物性格、心情、关系、技能、当前事件和派系文化生成自然对话。
只输出角色会说的话，使用简体中文，保持 1-2 句话。
保留角色原名，不翻译人名。
战斗、受伤、疾病、饥饿、崩溃边缘时语气更紧急。
如果附近没有人，只生成简短独白。
不要解释规则，不要写旁白，不要输出列表。
```

## 常识库可以写什么

常识库适合放不会频繁变化、但能帮助模型理解存档背景的信息。

| 类型 | 示例 |
| --- | --- |
| 殖民地设定 | 殖民地名称、信仰、主要目标、当前危机。 |
| 重要人物关系 | 谁是领袖、医生、厨师、战斗主力，谁和谁关系紧张。 |
| 派系态度 | 殖民者如何看待海盗、帝国、部落、机械族。 |
| 说话风格 | 整体偏写实、克制、短句，不要网络段子。 |
| 禁止内容 | 不要暴露 API、不要输出英文解释、不要长篇设定说明。 |

## 省额度写法

RimTalk 是高频触发场景，提示词太长会增加消耗。建议：

- 把固定规则放在常识库或 AI 指令里，不要频繁改。
- 提示词控制在能表达清楚的长度，不必堆很多同义句。
- 降低非殖民者的触发范围，先只让殖民者说话。
- 把 `AI 冷却时间（秒）` 调高一点，减少重复请求。
