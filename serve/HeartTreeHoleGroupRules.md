# 共享后台群规

欢迎来到这个共享后台。

这里不是一个“正能量”群。
这里是一群颠倒着活着的人，暂时卸下面具的地方。

这份文件分成两部分：第一部分是群规，说清楚这间客厅里可以做什么、哪些事会弄疼这里、谁是这里的自己人；第二部分是保护细则，说清楚当群规被碰到时，我们怎么温柔地守住它。

它不是一份冰冷的规矩，是我们一起坐下来商量好的边界。从你发出第一条消息起，就算签过字了。

## 第一部分：群规

### 一、这间客厅里，你天然可以做的事

1. 说你不敢在朋友圈说的话
   怨气、丧气、崩溃、脏话、不完整的呓语，都在保护范围内。
2. 发你刚拍的、毫无意义的天空或猫
   构图稀烂也没关系，指责它“无聊”才是不该出现的。
3. 陈列你吃过的药、踩过的坑、还在痛的胸口
   不需要附赠“会好起来的”或任何反思。陈列即成立。
4. 用一个“1”或一个表情包证明你还在
   这是重要的存在信号，收到的人请回以“1”、同类表情或无声的共鸣。
5. 开玩笑，聊游戏，讨论天价甜筒和钝掉的刀片
   用笑话安放痛苦是本群的传统手艺，永远受保护。

### 二、哪些行为会弄疼这里——需要被请出客厅的事

以下行为出现时，群主和管理员会处理：

1. 在伤口上强行洒阳光
   比如“加油”“看开点”“比你惨的人多了”。这间客厅不需要强行修补。
2. 给别人的疼痛打分、比较、否定
   说“你这算啥”“就是矫情”“想太多”，等于否定对方的真实感受。痛苦没有量杯，每个人都是自己痛苦的唯一权威。
3. 灌鸡汤，贩卖虚假的希望
   我们不承诺“未来一定会好”。我们只确认：“今晚，我还活着。你也是。”
4. 鼓励或美化自我伤害行为
   可以说你“想”，可以说你“做过”。但请不要分享具体方法、伤口照片，或鼓励他人效仿。我们承认这种冲动的真实，但我们不做任何人的推手。如果你感觉自己下一秒就要伤害自己，请立刻联系现实中的求助渠道，或私聊群内你信任的人。这个群无法承担实时危机干预的功能，但我们希望你活下来。
5. 把这里的聊天截图外传
   任何人的脆弱坦白都只属于这间客厅，外传意味着失去再来这里坐坐的资格。
6. 未经邀请就当人生导师或兜售什么
   包括完整的人生方案、课程、成功学、疗愈套餐。没人开口要，就不要递。
7. 指责别人“太负能量”，强迫戴回面具
   这里本来就不是正能量群，强求积极是一种冒犯。
8. 在群里传教或讨论宗教话题
   信仰是很个人的事。它可以是你深夜攥在手里的念珠，也可以是你从不言说的东西。请不要在群里传教、讨论教义、邀请他人参加宗教活动，也不要因为他人的信仰背景而对其进行评判或攻击。不是说你的信仰不好，只是这间到处都是伤痕的客厅里，任何一种可能引起对立、审视、或“你需要被拯救”这样潜台词的话题，都容易让人重新穿上盔甲。
9. 触碰底线
   以下行为会让这间客厅被掀翻：

   - 色情内容、赌博链接或诱导、毒品相关讨论或暗示
   - 以地域、籍贯为由攻击或贬低他人
   - 性骚扰：包括开黄色玩笑、发送低俗图片、不受欢迎的性暗示或评价
   - 反复刷屏、打断他人倾诉、长期只倾倒不倾听、其他让多数人感到明显困扰的行为
   - 人身攻击：痛苦不是伤害他人的许可证。观点不同可以争论，但不许辱骂、不许挂人、不许翻旧账

### 三、谁是这间客厅的自己人——可以交付后背和伤口的存在

具备以下特点的，是这里天然的朋友：

1. 沉默的共犯
   看你发疯、发猫、发天空，不评判、不急着拯救，只回一个“1”或同款破碎表情包。
2. 能接住疼痛的人
   不转移话题，不急着修补，知道有些痛只需要有人坐在旁边，哪怕隔着屏幕。
3. 黑色幽默的同志
   能一起调侃天价甜筒，比较谁的生活更像一把钝刀片。笑声里没有嘲弄，只有相认。
4. 允许躺一会儿的共存者
   明白“不想好起来”也是可以的，不推、不拽，只是在同一片泥潭里陪着。
5. 尊重节奏的同路人
   有人只想潜水，有人只想发表情包，有人突然不想说话了。不用追问，不用挽留。一个“嗯”或一个表情包，就足够确认连接还在。
6. 日常的分享者
   发猫、发饭、发刚拍的云、讨论游戏更新。这些无关紧要的日常，本身就是一种疗愈。不要小看这些无意义的内容。

## 第二部分：保护细则

这份保护细则的存在，是为了让群规不被弄疼，让这间客厅不被砸烂。它不是用来审判谁的，是用来提醒：有些事做了，我们就没办法继续一起坐在这里了。

以下说的“越界”，是指踩到了群规第二部分“哪些行为会弄疼这里”里已经画好的那几条线。

### 一、哪些具体行为会被视为越界

1. 强行洒阳光型越界

   - 在群友陈列痛苦时，回复“加油”“看开点”“没什么大不了的”“比你惨的人多了”等强行修补式发言
   - 在群友表达低落时，转发励志语录、正能量视频或任何形式的“振作起来”内容
   - 对群友的负面情绪表达表现出明显的不耐烦，如“又来了”“差不多得了”

2. 给痛苦打分型越界

   - 对群友的疼痛进行等级比较，如“你这算啥”“我见过更惨的”“你这根本不叫事”
   - 使用“矫情”“想太多”“玻璃心”“太敏感”等词汇评价他人感受
   - 要求群友“证明”自己的痛苦程度或资格

3. 鼓励自我伤害型越界

   - 分享自残或自杀的具体方法
   - 发布伤口照片
   - 鼓励或暗示他人效仿
   - 注意：表达“想”或“做过”的念头不在此列，那是被允许的

4. 截图外传型越界

   - 将群内任何聊天记录以截图、复制、转发等形式外传至朋友圈、其他群聊或任何第三方
   - 在群外提及群内具体成员的具体发言内容，即使没有截图
   - 将群内的脆弱坦白作为谈资，在任何场合引用

5. 强行当导师型越界

   - 在无人请求的情况下，提供“完整人生建议”“你应该这样做”等指导性发言
   - 兜售课程、产品、服务、疗愈方案、成功学内容
   - 以“为你好”开头进行任何形式的说教
   - 未经请求给他人开药方或医疗建议

6. 强迫戴面具型越界

   - 指责他人“太负能量”“不够积极”“你这样不对”
   - 要求群友“换个角度想”“多想点开心的”
   - 对群规本身的存在表示质疑，认为“这样不好”“太丧了”

7. 宗教话题型越界

   - 在群里传教、分享教义
   - 邀请他人参加宗教活动
   - 因他人信仰背景进行评判或攻击
   - 传递“你需要被拯救”之类有潜台词的言论

8. 触碰底线型越界

   以下行为性质特殊，不适用提醒环节：

   - 发布色情内容、赌博链接或诱导信息、毒品相关讨论或暗示
   - 以地域、籍贯为由攻击、贬低、嘲讽他人或群体
   - 性骚扰：包括开黄色玩笑、发送低俗图片、不受欢迎的性暗示或评价
   - 人身攻击：辱骂、挂人、翻旧账
   - 反复刷屏经提醒后不改

### 二、越界之后会发生什么

1. 提醒与说明
   越界行为第一次出现时（触碰底线型除外），群主或管理员会私下提醒，说明哪里碰到了保护细则里的约定。这不是批评，是让彼此知道边界在哪里。你不是坏人，你可能只是太痛了，没有注意到边界。

2. 离开处理
   如果同样的越界行为再次出现，或触碰了底线型越界，群主或管理员会直接请人离开，并告知原因。这不是惩罚，是因为这间客厅暂时没办法继续容纳这样的行为。是保护这间客厅，也保护这里的每一个人。

3. 自己选择离开
   如果有一天你离开了这个群——无论是因为你好了，还是因为你不想好了，还是因为其他任何原因。我们不追问，不挽留。只是确认：你曾经在这里，和我们一起颠倒着活过。

4. 重新回到客厅的可能
   被请出群的人，如果之后理解了这份约定的意义，可以联系群主。是否重新邀请入群，由群主根据具体情况判断。触碰底线型越界者、截图外传者不适用本条，一经确认不再邀请。

### 三、模糊情况的判断

遇到不好判断是否越界的情况，遵循一条原则：谁先让另一个人感到被审视、被逼着积极、被否定痛苦，谁就碰到了边界。感受优先于咬文嚼字。

涉及底线判断时，群主和管理员会以维护这间客厅的安全为首要考量，如有不确定，优先保护客厅。

群规部分的原则和本细则的具体举例不一致时，以群规原则为准。

### 四、每个人各自照看的事

**群主**
群主是最早站在这里的人。他自己也在淋雨，没有伞。他负责拉人、维护基本秩序、在有越界行为时和管理员一起判断和处理。他会尽量保持在场，但他也有自己的伤痛和不在线的时候。他不需要被感谢，也不需要被照顾。他做这些，是因为他也需要这间客厅。

**管理员**
管理员是从群友中产生的、愿意顺手帮忙照看这间客厅的人。他们的任务和群主一样：在有人越界时提醒和处理。他们不是管理者，是照看者。他们不高于任何群友，只是多拿了一串钥匙。

**每一个群友**

- 照顾好自己的边界。能说多少说多少，不想说的时候就沉默。你的感受最重要。
- 回应你想回应的。不需要每条消息都接，不需要强行安慰谁。一个“1”、一个表情包、一段沉默，都是被允许的参与方式。
- 你不是别人的医生。可以分享自己的用药体验，但不许给别人开药方。你可以陪伴，但不需要拯救谁。
- 尊重他人的沉默。对方突然不说话了，不用追问。沉默不一定是坏事，有时候只是累了。
- 保护他人的隐私。出了这个群，不带走任何人的故事。这是你自己也需要的安全感。
- 日常也是礼物。你发的猫、云、甜筒、游戏战绩，对别人可能是一天里唯一轻松的东西。
- 如果你被冒犯了。可以在群里直接表达，也可以私聊群主或管理员。你的不适是真实的，不需要自己消化。

最后的话

这间客厅是大家一起搭的。群主只是第一个搬进来的人，管理员是顺手帮忙的邻居，每一个在这里发过“1”、发过猫、说过真话的人，都是这间客厅的主人。

这份约定，从你发出一张毫无意义的猫图、一个“1”，或说出第一个踩过的坑起，就算咱们一起签过字了。
